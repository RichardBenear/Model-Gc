# EX-GC24A — revised exploratory protocol

PI approved testing after Claude review 5fd7aa5. Keep EX-GC24 proposal unchanged. No orbital runs. Single-threaded spectral tests; Stage A budget 0.5 core-hour. All quantities in existing model units, force proxy 2 integral(s Jz/G). Weak-depletion branch uses G=1 in force only, compensated periodic mean, normalized Gaussian.

* A1/A2: continuum Fourier sums with zero mode excluded; reference S=5.32, sigma=.8, c=2, tauJ=20, L=32, h=.5. Sweep omega=.001,.003,.01,.03,.1,.3; tauJ=.25,2,20,200; S=.266,2.66,5.32,10.64; sigma=.4,.8,1.6; c=1,2,4; L=16,32,64; h=.5,.25 at L=16. One variable at a time. Compute finite damping low-frequency expansion and lossless integral. Compare +/- constant velocity .01,.025,.05, zero; evaluate G=1 and actual depletion weight for reference and weak source. No parameter fitting.
* A3: independently integrate first-order wave equations for all modes of a small periodic box (L=12,h=.75,c=2,tauJ=2,omega=.5); translated normalized Gaussian, initial static equilibrium, six periods, fit final two; dt <= .02, halve dt and displacement amplitude (.02,.01). Compare linear impedance within 1% or flag failure.
* A4: compare explicit inherited absorption term -s V with self-wake, including native localization weight s/(s+.001 max(s)); measure force difference with +/- velocity and zero, applied flux +/- .02. This is a conditional test of the existing continuum closure, not a derivation of head-on absorption from wave equations. Also report total m/b against EX-GC23 20-unit tracking interval and weak/strong scaling. If nominal time < 1 model unit and < 1/20 of tracking interval, stop Stage B under this closure; distinguish uncertainty about physical drag law.
* A5: independently assess cost of h=.125 full chemical evolution from EX-GC23 recorded timings, and perform inexpensive matched-grid instantaneous centroid transport diagnostic on interpolated saved rest fields. This is not a replacement for independently settled fine-grid coasts; explicitly leave those unresolved if computationally disproportionate. No claiming continuum convergence from this diagnostic.

Record all runs, settings, numerical errors and limitations. Stop if nonfinite values, invalid G or failed validation. No remote writes; package reproducible results locally.

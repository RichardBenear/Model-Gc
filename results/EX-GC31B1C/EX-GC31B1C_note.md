## Construction
Active graph finite simple undirected, edge instances separately identified. Each event consumes exactly one live edge {a,b}, retains endpoints, creates fresh internal vertices and replaces the edge by a terminal-symmetric gadget. S: a-w-b (2 edges, 1 new vertex). D: a-p, p-r, r-q, p-s, s-q, q-b (6 edges, 4 new vertices; two equal paths within a diamond, terminals each degree 1). New vertices/edges have constructor identity up to terminal reversal and interior symmetry; no physical numbers or coordinates. Edge producer record immutable, active edge retired. Event identity is consumed instance; seed edges grade 0, children grade parent+1. Grade is an observation of ancestry, not global physical time or update condition in unrestricted execution. Finite cut simulator restricts events to grade≤R. No deleting vertices, no destructive choice of multiple events on one edge.

## Exact proof
Two distinct eligible events consume distinct edges. They may share an endpoint, but endpoints are unchanged (only live incidence changes; match tests the input edge only). Distinct fresh namespaces ensure both remain enabled and their output edges cannot collide. Both orders preserve all same live edges and immutable history/producer arcs. If same input edge, same event identity, not a choice. Induct on grade: every live seed/child instance has exactly one event and finite child set; all fair schedules eventually consume each grade<R edge and generate all grade≤R descendants. Thus the same completed cut/producer DAG is obtained, and the countable union is unique for fair schedules. Arbitrary partial cuts need not have equal active graphs. Proof covers exclusive consumption with unique owner, not genuine competing consumption of a shared edge. Relabeling induces bijection of events, children and live edges (D's terminal reversal swaps p/q, r/s interchangeable); canonical constructor tags are bookkeeping.

Each gadget has terminal degree exactly one, so replacing an edge preserves degrees of all pre-existing vertices. Fresh degrees ≤2 (S) or ≤3 (D). Consequently max live vertex degree ≤max(initial maximum degree, gadget max degree) at every event, independent of schedule and depth. Connectivity preserved because each gadget connects both old terminals. Every earlier edge instance is retired at completed depth R. Old vertices remain; this is relational, not constituent turnover.

For m seed edges, n seed vertices and k replacement edges, q internal vertices, L shortest terminal distance: E_R=m k^R, total events/retirements N_R=m(k^R−1)/(k−1), V_R=n+qN_R. All old seed vertex distances multiply by L^R: every substituted edge connects externally only at the two endpoints, any route between old vertices projects to a seed walk, and each crossed gadget costs at least L per refinement. The exponent log(k)/log(L) is exact for this edge count vs terminal distance sequence (S=1, D=log6/log4≈1.29248), NOT a measured Hausdorff/spacetime dimension. S preserves cycle rank E−V+1; D adds exactly one per event. Both laws generate a fixed self-similar refinement of seed geometry, not a demonstration of dimension selection.

## Deeper obstruction and decision
H1 restricted causal invariance PASS; active relation turnover, local finiteness and endpoint-overlap PASS. However event DAG is a forest of k-ary trees rooted in seed edges (each event consumes exactly one instance, and has exactly one producer parent except seed-root events). Shared endpoints do not create causal dependency or convey state changes; no event can have two independent parents. Descendants of distinct seed edges can never meet in the producer DAG, and sibling branches never communicate through subsequent events. Even D's spatial cycles have no causal joins: spatial connectivity must not be mistaken for operational propagation. A perturbation confined to one seed edge can only directly change its descendant event tree under the defined match law, absent a new interaction rule. This is a stronger limitation than fixed refinement geometry; no independently defined interacting excitation and no common operational light cone. H2 structural support in spatial graph is not an operational result; H3–H6 unestablished. No B2/B3 on these candidates. 

Recommended next (requires PI go-ahead): GC31B1D, a native multi-input rendezvous rule with jointly consumed unique tokens and local ownership determined by incidence/provenance, so independent causal branches can actually merge while alternative overlapping events cannot steal inputs. Require nonvacuous concurrency, actual multi-parent causal joins, active relation/vertex turnover and bounded degree, and no externally imposed spatial scaffold. Check whether native routing already fixes topology or dispersion, and do not equate local port matching with emergent common metric. A positive toy construction may still require prescribed wiring; reject that as a physical candidate while retaining as control. Genuine competing destructive matches remain a separate open design problem. No energy/gravity claim and no next production authorized.

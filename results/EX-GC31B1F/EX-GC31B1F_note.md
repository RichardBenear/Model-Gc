## Construction
A finite directed relational port graph has exactly one incoming and outgoing slot of each of two intrinsic colors 0,1 per vertex. Each color is a permutation on the current vertex set. Logical loops and multiple bonds allowed; total degree counts four incidences (including loop ends). Vertex fires once when its four incidence tokens ready; retires, creates daughters labelled by route words W={0,1,00,01,10,11}, and connects them in the specified directed internal cycle (new color1). Each daughter reserves an incoming/outgoing external slot (new color0). A request from daughter w follows the old vertex's outgoing descriptor w[0]; for length 2 it waits for the intermediate vertex event then relays via its old descriptor w[1]. At destination waits for destination split then connects to destination's w daughter. Old descriptors immutable history, not active links; all routing determined by old port incidence/word, never seed ancestry or numeric IDs. Each route consumes its unique request and fills a unique destination slot. Relay and join events carry source/relay/destination and descriptor producer dependencies. Implementation waits for real vertex readiness and emits route requests online; no externally supplied next graph. One-hop-only control S uses W={0,1}, same internal cycle and local protocol. P includes two hop routes. Word order, port colors, addressable slots and inherited within-vertex gadget are explicitly imposed ontology; not an unlabelled arbitrary rewrite rule.

## Proof
For old permutations P0,P1, each word w yields composition Pw (first symbol applied first), also bijective. For each destination vertex and each w there is exactly one source and therefore one corresponding reserved incoming slot; each source has one outgoing request per w. Intermediate relay slot also unique per word via the first color's bijection. Independent vertex events retire separate owners and produce disjoint daughter namespaces. Request/relay/join events use immutable historical descriptors; mutually enabled events cannot steal one another's inputs, and outgoing/incoming slots are distinct even for loops. All simultaneous ready-event pairs commute up to identity normalization. An event is either not ready or has a unique action, no competing destructive match claimant. For finite depth R, events stratified by local generation, split then optional relay then join at each generation; next vertex waits for all four new ports. Every required predecessor is finite, no higher-generation event can invalidate a lower one. Induction yields unique complete cut and producer DAG for all fair schedules, including countable history union. No global scheduler clock, though generation/word/port protocol defines a strong local refinement structure. Arbitrary incomplete cuts need not be identical or fully connected. Numerical relabeling commutes with constructors; colors are physical protocol, not tested as gauge.

Color1 is a disjoint cycle per split, color0 is disjoint bijections on same-word daughter sets; hence each vertex has exactly four incidences at completed cuts and at most four reserved slots at any partial cut. Each generation consumes prior live vertices/port incidences; old bonds retained only as history. |V_R|=N|W|^R, |B_R|=2|V_R|. Existing root-pair adjacency survives via length1 requests and internal cycle connections; a two-hop route can connect descendants of nonadjacent roots when two old path endpoints were not adjacent. No route can leave an original connected component; one-hop routes plus internal cycles preserve each component. S never introduces an ancestral neighbor pair by induction. No output involves disconnected components and no instantaneous nonlocal signaling is inferred.

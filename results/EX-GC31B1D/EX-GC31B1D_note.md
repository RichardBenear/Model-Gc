## Rule
A connected finite seed graph, max degree 3, has two separately owned ends per bond, each with an inbound FIFO of tokens (initially one). A vertex event waits for one head token on EVERY owned end; consumes them jointly, retires itself and sends one token to every opposite end. Replacement either clones the vertex (all ends inherited by one new vertex), or makes d daughter vertices each owning one old end and connects every pair by a new internal bond, with one initial token per direction produced by this event. d≤3, so split is a single daughter, edge, or triangle. S always splits; R sends the OR of input bits and splits if bit=1, clones if 0. R0 all zero; R1 marked inbound end of first seed edge at its first listed root. Same R rule, one input perturbation only. Bit is a classical information marker, not energy, momentum or entanglement. No global scheduler clock; labels used solely for enumeration and constructor identities. Bond ID persists but current endpoint owners change; live geometric edge is derived from current owners, not separately consumed. Initial seed graph is a seed, not coordinate lattice, but routing interfaces and replacement shape are imposed. No removal of bond IDs.

## Proof: exact restricted causal invariance
Event identity is current vertex instance, enabled by unique inbound heads. Distinct ready vertices consume disjoint tokens and retire disjoint owners, including adjacent vertices. On a shared bond one event pops its own inbound head and appends to the opposite queue; the other event's already-ready head cannot change under append. Pop and append commute when head exists. Owner transfer affects only own end; sender addresses persistent opposite end rather than old owner. New internal bonds/vertices fresh per constructor, so both orders produce identical owner map, queues, tokens, outputs and producer/consumer arcs (including owner birth and each head's producer). No alternative claimant may consume the same token. This is structural avoidance of destructive conflict, not a solution for unrestricted overlapping consumptive matches.

Unit token balance on each bond: queue lengths q_a=1+n_b−n_a, q_b=1+n_a−n_b, where n_a,n_b count firings on each end since bond creation. Nonnegativity forces 0≤q_a,q_b≤2 and sum 2. This holds under adaptive owner reassignment. Each new internal bond starts with one each. Every old port is inherited exactly once; clone retains degree d, split daughter has 1+(d−1)=d. Thus live max degree≤3 at any cut; connectedness follows from connected local clique replacement. All events retire one vertex; each old port incidence replaced, not all bonds erased.

Event grade is 1+max(owner birth grade, consumed token grades), seed grade 0. In a finite grade-R cut, at most finitely many vertices from a bounded-branching daughter tree, one event each. Ready rank-eligible events persist until fired; higher-rank append cannot alter a lower-rank ready head. Local diamonds plus termination imply unique completed cut, including complete recorded producer DAG (not mere endpoint counts). For unrestricted fair execution, each finite cut is the same: every finite eligible event with known finite lower-grade parents becomes ready after those dependencies occur, remains ready, and eventually fires. Higher-grade events neither steal its heads nor retire its owner. Equivalently a missing input for a rank-eligible event must be supplied by a lower-grade firing; projecting an unrestricted history to grade≤R preserves legal transitions and fair completion. Arbitrary partial prefixes need not be identical. This proves fair-history equality in this explicit port ontology, not physical Lorentz invariance.

## Exact remaining obstruction: ancestry bottlenecks
Consider all active descendants of one birth vertex at any later cut. Its boundary bonds are exactly that vertex's original incident bonds: each replacement only transfers the same boundary ends and creates new bonds inside the descendant patch. No new link crosses patch boundary. Thus boundary size ≤3 forever, even when patch volume grows unbounded under S (or persistent R marker). The graph is a hierarchical refinement with permanent finite-port bottlenecks, not unrestricted rewiring or self-selected homogeneous 3D geometry. This is an exact structural limitation, independent of finite sample. It does not alone rule out all useful coarse-graining, but cannot establish macroscopic manifoldlike geometry or a universal operational metric. Compare CRR/StochasticVacuum lesson: fixed degree or local dimension is insufficient. No B2/B3 opened as physics production on this rule. H1 restricted pass; genuine multi-parent interaction pass; active geometry response pass by construction; H2–H6 not established. No physical energy, stress, mass, tensor or ZPF inference.

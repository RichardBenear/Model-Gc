## Native immutable pair join J
Given distinct simple undirected relational edge instances e={a,b}, f={b,c}, a≠c, fire once for their unordered pair. Retain e,f, create fresh w (constructor identity determined by pair), add two distinct edges {a,w},{c,w}. Each new edge is identified by its producer and endpoint (equivalently by the endpoint pair, since w is fresh). A pair's unique constructor is a local single-fire guard; this is extra ontology (immutable provenance and idempotent events), not the original destructive CRR law. No coordinate, clock, schedule selector, or explicit spatial dimension is used.

## Proof
Each enabled event depends on the two input edge producers, except initial edges. No event removes or modifies any input. If distinct enabled E,F overlap in an input, both remain enabled after the other fires; neither can allocate the other's fresh vertex or output identity, so E;F and F;E give identical edge and event sets and producer DAG (with read multiplicity). If the event identity is identical, it is a single idempotent event, not two choices. Disjoint events commute for the same reason. No competing exclusive-consumption match is admitted. This is a constructive solution for overlaps **by avoiding destructive conflict**, not a theorem for general consumptive grammars.

Set seed edge grade 0, new event grade 1+max(input grades), and outputs inherit event grade. For each fixed R, the grade≤R closure is finite by induction (at most all unordered pairs of finite prior-grade edges). Every event's dependencies have strictly lower grade; all possible events at grade r are a deterministic function of the preceding grade closure. Any fair execution fires each enabled pair eventually. By induction all grade≤R event instances eventually occur with identical inputs, outputs, producer dependencies; no higher-grade event can change this set. Consequently all fair complete histories have the same constructor-identified DAG; arbitrary partial prefixes need not coincide. The cutoff is an observation cut, not physical time or a synchronization rule. The proof also covers the unrestricted countable union of all finite-grade cuts for fair histories. Relabeling initial vertices commutes with the constructor and maps the complete DAG/edge graph bijectively. An implementation using global storage is only an enumerator of local matches.

## Frozen tests
Five seeds, grades 1–3, four ordering strategies (ascending, descending, two RNG seeds), original and permuted seed labels: 120/120 exact equality to the reference cut including normalized vertices, edge identities/endpoints/producers and event IDs/producer arcs. 96/96 nontrivial cases exhibit overlapping eligible reads; 24 single-edge inert cases have no event. Every resulting seed-connected graph stays connected. Negative control on four-edge path using destructive pair deletion (no outputs): central pair first leaves two isolated edges and halts after one event; two outer pairs in either order halt after two independent events. Different maximal DAG sizes show a real causal-invariance failure in that control. This is a distinct rule, not a failed arm of J.

## Structural obstruction: permanent hubs
For any seed path a-b-c, the event on {a,b},{b,c} produces w1 connected to a,c. The pair at w1 produces w2 connected to a,c, and so on without consuming anything. Every distinct new w_i forms another length-two path between the same a,c. Thus both endpoint degrees diverge as grade increases (at least linearly along this explicit chain), and radius-two neighborhoods grow without bound around those persistent endpoints. The initial vertices are privileged by longevity; the cumulative mean degree approaches 4 in any unbounded run (each event adds exactly one vertex and two edges), so a modest mean degree does not remove the hub issue. Also no relation/vertex turnover, no independently defined local excitation, no operational signal speed. This is a graph of retained history, not yet a viable evolving spatial slice. The bound does not prove no coarse-grained geometry exists, but a naive instantaneous spatial metric based on all retained edges is not a good candidate for stable locally finite vacuum. H1 restricted ontology PASS; genuine shared-edge eligibility PASS; destructive-conflict completion not tested/not supported; H2–H6 not established. In particular causal invariance is not common light cone (GC31A).

## Decision
Do not open B2/B3 on the raw cumulative graph solely on this pass. Keep J as a reference exact causal-history generator. Next design question: can active spatial relations turn over while immutable event ancestry remains available, without invoking a global scheduler or simply selecting the branch that preserves particles? Seek locally consistent event completion (e.g. unique producer-linked ownership for consumable tokens plus shared read guards that cannot be invalidated by rival events, or explicit coherent completion of genuinely competing rewrites), then test nontrivial active-front dynamics and bounded degree. Any such rule needs its own proof; restricting branch choice could trivialize causal invariance as in CRR singleton vacuum. Distinguish retained causal history from active geometry, independently reconstruct intervals/clocks; geometry diagnostics and two-mode propagation remain later gates. No claim energy, mass, gravity, entanglement or induced stiffness. Review deferred; future production requires PI go-ahead.
